# Chiru.OS — Developer Portfolio

A developer portfolio built with React and Vite, featuring a terminal-inspired interface, responsive layouts, and a persistent light/dark theme.

## Overview

Chiru.OS is my personal portfolio for showcasing software projects, technical skills, and development experience. I designed it as a minimal developer workspace with a focus on readability, usability, and practical project work.

## Features

- Terminal-inspired visual design
- Responsive layout for desktop and mobile
- Light and dark themes with saved preference
- Project cards with repository and live-demo links
- Dedicated sections for introduction, skills, projects, and contact
- Resume download
- Smooth section navigation

## Tech Stack

- **Frontend:** React, JavaScript
- **Build tool:** Vite
- **Styling:** CSS
- **Code quality:** ESLint

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/chiranjeevi-kodimela/chiru-os.git
cd chiru-os
npm install
npm run dev
```

Open the local URL printed in your terminal.

### Available Scripts

```bash
npm run dev
npm run lint
npm run build
```

- `dev` starts the local development server.
- `lint` checks the code for linting issues.
- `build` creates a production build.
